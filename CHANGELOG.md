# FolioPod Change Log

Noted below are the high level changes for the app.  Each update
includes a short user-oriented description, version number, date, and
developer.

You can run the app in your
[**browser**](https://foliopod.solidcommunity.au) or else download and
install locally the latest version from the [Solid Community
AU](https://solidcommunity.au) or directly:

+ **Android** as
[apk](https://solidcommunity.au/installers/foliopod.apk) or
[aab](https://solidcommunity.au/installers/foliopod.aab);
+ **GNU/Linux** as
[deb](https://solidcommunity.au/installers/foliopod_amd64.deb) or
[snap](https://solidcommunity.au/installers/foliopod_amd64.snap) or
[zip](https://solidcommunity.au/installers/foliopod-linux.zip);
+ **macOS** as
[dmg](https://solidcommunity.au/installers/foliopod-macos.dmg) or
[zip](https://solidcommunity.au/installers/foliopod-macos.zip);
+ **Windows** as
[exe](https://solidcommunity.au/installers/foliopod-windows-inno.exe)
or [zip](https://solidcommunity.au/installers/foliopod-windows.zip).

Contributions are welcome. Visit
[github](https://github.com/gjwgit/foliopod) to submit an issue or, even
better, fork the repository yourself, update the code, and submit a
Pull Request. Coding documentation is
[available](https://solidcommunity.au/docs/foliopod/).

We make this project available for free so if you appreciate the app
then please show some ❤️ and tap on the star at
[GitHub](https://github.com/gjwgit/foliopod) to support our work.

This app is authored by [Graham
Williams](https://togaware.com/Graham.Williams.html).
